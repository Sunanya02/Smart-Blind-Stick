# Smart-Blind-Stick
An IoT-based Smart Blind Stick that helps visually impaired people detect obstacles using ultrasonic sensors.

## Features
- Obstacle Detection
- Buzzer Alert
- Portable Design
- Low Cost

## Components
- Arduino UNO
- Ultrasonic Sensor (HC-SR04)
- Buzzer
- Battery
- Jumper Wires

## Working
The ultrasonic sensor measures the distance to obstacles. If an object is detected within a predefined range, the buzzer alerts the user.

## Technologies Used
- Arduino IDE
- Embedded C++
